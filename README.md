# 喫茶 余白 — 歩いて、手にとる

アンティーク喫茶店を歩き、コーヒー・プリン・クリームソーダを手にとるGodot製3Dプロトタイプです。

## 操作

- PC: WASD / 矢印キーで移動、ドラッグで見回す、Eで手にとる
- スマートフォン: 画面の移動ボタン、ドラッグ、品物のタップ
- 手にとった品物はドラッグまたは矢印ボタンで回転。「戻す」でテーブルへ
- メニューから操作説明、視点と進行のリセットができます

## 実行環境

WebGL 2 と Compression Streams API に対応するブラウザーが必要です。ゲーム本体は Godot 4.6.3 で作成しています。WASMはgzip形式で配信し、ブラウザーで展開します。
