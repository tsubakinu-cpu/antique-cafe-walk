喫茶 余白 — 歩いて、手にとる

HTTPサーバーから index.html を開いてください。file:// では起動しません。
WASD / 矢印キーで歩く。画面ドラッグで見回す。近くの品をクリック／タップ、または E で手にとる。
手にとったらドラッグで回転。戻す / E / Esc で返す。メニュー / Esc で一時停止。
タッチ画面では左下の移動ボタンを使います。
コーヒー、プリン、クリームソーダの三品を眺める小さな探索プロトタイプ。タイマーや失敗はありません。

Godot 4.6.3 Compatibility renderer / WebGL 2 / single-threaded Web runtime
埋め込み日本語フォント: Noto Sans CJK JP (OFL)。LICENSEファイル参照。

GitHub Pages 用に index.wasm を gzip 圧縮しています。ブラウザ標準の DecompressionStream が必要です。
wasm-gzip-adapter.js は同じ配信元の index.wasm だけを index.wasm.gz から展開します。
ゲーム本体の index.js・index.pck は通常版と同一です。
